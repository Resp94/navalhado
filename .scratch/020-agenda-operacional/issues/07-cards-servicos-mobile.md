# 07 — Compactar cards de serviços no mobile

**What to build:** Reorganizar os cards de serviços para aproveitar melhor telas mobile, mantendo as informações e ações essenciais acessíveis sem alterar a experiência desktop.

**Blocked by:** None — can start immediately

**Status:** completed

- [x] Em largura próxima de 390px, os cards não produzem overflow horizontal.
- [x] O layout prioriza nome, preço, duração, status e ações nessa ordem visual.
- [x] Espaços internos, áreas vazias e altura excessiva são reduzidos sem prejudicar leitura.
- [x] Nomes longos quebram de forma adequada e não empurram preço ou ações para fora do card.
- [x] Editar, excluir e ações equivalentes permanecem facilmente acionáveis por toque.
- [x] A versão desktop mantém o layout e o comportamento atuais.
- [x] Existem testes/regressões visuais ou de renderização para nomes longos, status, ações, 390px e desktop.
