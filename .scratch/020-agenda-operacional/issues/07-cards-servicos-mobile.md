# 07 — Compactar cards de serviços no mobile

**What to build:** Reorganizar os cards de serviços para aproveitar melhor telas mobile, mantendo as informações e ações essenciais acessíveis sem alterar a experiência desktop.

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] Em largura próxima de 390px, os cards não produzem overflow horizontal.
- [ ] O layout prioriza nome, preço, duração, status e ações nessa ordem visual.
- [ ] Espaços internos, áreas vazias e altura excessiva são reduzidos sem prejudicar leitura.
- [ ] Nomes longos quebram de forma adequada e não empurram preço ou ações para fora do card.
- [ ] Editar, excluir e ações equivalentes permanecem facilmente acionáveis por toque.
- [ ] A versão desktop mantém o layout e o comportamento atuais.
- [ ] Existem testes/regressões visuais ou de renderização para nomes longos, status, ações, 390px e desktop.
