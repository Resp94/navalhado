# 02 — Resumo diário no mobile

**What to build:** O gerente consegue consultar no celular o mesmo resumo diário disponível no desktop, com leitura rápida de faturamento realizado, entradas no caixa e data selecionada.

**Blocked by:** 01 — MVP de faturamento diário no Caixa

**Status:** ready-for-agent

- [ ] Consumir o mesmo contrato de resumo diário usado pela visão desktop.
- [ ] Exibir cards compactos para faturamento realizado e entradas no caixa.
- [ ] Exibir lista vertical do resumo diário com filtro de data acessível por toque.
- [ ] Manter os cards e ações atuais de gaveta, PIX, cartão, abertura, fechamento, suprimento e sangria.
- [ ] Respeitar design tokens, safe area, estados de carregamento, vazio e erro.
- [ ] Garantir que desktop e mobile apresentem os mesmos valores para a mesma data.
- [ ] Cobrir a visão mobile com testes de comportamento.
